Cookie Minimizer privacy statement (draft, review before release)

Cookie Minimizer reads website content in the browser solely to identify cookie consent dialogs and interact with consent controls. It does not send a user's browsing history, cookies, consent decisions, or page contents to any server. It makes no extension-initiated network requests.

The extension saves only these preferences in the browser's storage.local: whether automation is enabled, whether to automatically save safe category choices, and a list of excluded domains. These choices remain on that device/browser profile. Firefox Android does not automatically sync this extension's settings to other devices.

The extension does not read cookie values using the Cookies API, and does not remove cookies that sites have already set. Consent detection can fail on some sites, especially cross-origin, closed-shadow-DOM, or custom-script interfaces. It does not prevent all tracking.

This statement covers the supplied source code, not any modifications a future publisher makes. An app distributor should supply their actual contact details and review Apple/Mozilla/Google privacy disclosures before release.
